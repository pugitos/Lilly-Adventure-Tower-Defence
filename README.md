# Lilly-Adventure-Tower-Defence
This Game is one of my scrap project and was the first game I created. Don't expect much. This is a 3d tower defense game. Gather material and discover new tower builds and build a village.
Currently there only one level for the build.

# Controls
wsad - move
q - attack
tab - build
f - interact
esc - close game
